## 1. 引言

### 1.1 软件简介

Dipper Worker 是一款运行在桌面端的 AI 协作助手。用户通过自然语言对话，即可完成文件操作、代码执行、网页检索、浏览器自动化、图片文字识别、文档生成等工作。软件同时提供内置浏览器、终端、文件面板、截图标注等桌面协作能力，帮助用户在本地工作区高效完成各类任务。

### 1.2 主要特性

- **简单**：添加工作区、配置 AI 服务商与模型后即可开始对话；内置 20 家主流模型服务商目录，支持一键选择并自动拉取模型列表。
- **高效**：Agent 自动调度内置工具包及可选工作区插件；回合结束后台沉淀记忆与可复用技能，使用越久越顺手。
- **可靠**：API 密钥经操作系统安全存储加密保存；权限门控、授权文件夹、路径守卫与网络守卫多重约束；会话数据本地持久化。
- **经济**：纯本地桌面应用，无订阅、无中间服务；对话自动节约词元使用量，长会话自动摘要压缩。

### 1.3 文档说明

本手册介绍 Dipper Worker V1.0.1 面向终端用户的安装、配置与日常操作方法。文中界面名称以中文界面为准；若使用英文界面，对应英文标签见设置中的语言选项。

## 2. 运行环境

### 2.1 硬件要求

| 项目 | 最低要求 | 推荐配置 |
|------|----------|----------|
| 处理器 | 双核 64 位 | 四核及以上 |
| 内存 | 4 GB | 8 GB 及以上 |
| 硬盘空间 | 500 MB 可用空间 | 2 GB 及以上 |
| 显示器 | 1280×720 | 1920×1080 及以上 |

### 2.2 软件要求

| 平台 | 支持版本 |
|------|----------|
| Windows | Windows 10 / 11（64 位） |
| macOS | Apple Silicon（arm64） |
| Linux | x64，支持 AppImage 运行环境 |

### 2.3 网络要求

- 使用云端大语言模型时需连接互联网，以便访问用户自行配置的 API 端点。
- 软件不托管用户对话内容，请求由本机直接发往用户配置的 API 地址。
- 使用本地模型时，可不依赖外网（视本地部署方式而定）。

## 3. 安装与启动

### 3.1 获取安装包

根据操作系统选择对应安装包：

| 平台 | 安装包类型 | 文件名示例 |
|------|------------|------------|
| Windows | 便携版 | `Dipper Worker-1.0.1-win-x64-portable.exe` |
| Windows | 安装程序 | `Dipper Worker-1.0.1-win-x64-setup.exe` |
| macOS | 磁盘映像 | `Dipper Worker-1.0.1-mac-arm64.dmg` |
| Linux | AppImage | `Dipper Worker-1.0.1-linux-x64.AppImage` |

### 3.2 Windows 安装步骤

**方式一：安装程序（NSIS）**

1. 双击 `Dipper Worker-1.0.1-win-x64-setup.exe`。
2. 按安装向导提示选择安装目录，点击「下一步」直至完成。
3. 安装完成后，从开始菜单或桌面快捷方式启动「Dipper Worker」。

**方式二：便携版**

1. 将 `Dipper Worker-1.0.1-win-x64-portable.exe` 复制到任意目录。
2. 双击运行，无需安装。

### 3.3 macOS 安装步骤

1. 双击 `Dipper Worker-1.0.1-mac-arm64.dmg` 打开磁盘映像。
2. 将「Dipper Worker」图标拖入「应用程序」文件夹。
3. 在「应用程序」中双击启动；若系统提示安全限制，在「系统设置 → 隐私与安全性」中允许运行。

### 3.4 Linux 安装步骤

1. 下载 `Dipper Worker-1.0.1-linux-x64.AppImage`。
2. 在终端中为文件添加可执行权限：`chmod +x Dipper\ Worker-1.0.1-linux-x64.AppImage`。
3. 双击或在终端中执行该文件启动应用。

### 3.5 首次启动

1. 启动应用后，若已有实例在运行，新实例会自动退出（单实例锁）。
2. 首次启动显示欢迎界面，提示添加工作区并配置 AI。
3. 关闭主窗口后，应用驻留系统托盘，可随时唤回（见第 17 章）。

## 5. 首次使用与配置

### 5.1 添加工作区

工作区是用户本地文件夹，Agent 在此目录内读写文件、执行命令并保存会话数据。

**操作步骤：**

1. 启动应用，在欢迎界面点击「添加工作区」；或在左侧边栏「工作区」标题旁点击「+」。
2. 在系统文件夹选择对话框中，选中一个本地目录（如项目文件夹）。
3. 点击「选择文件夹」确认。
4. 工作区出现在左侧边栏，显示所选目录名称。

**说明：** 可随时通过工作区选项菜单「更换工作区」切换目录；「移除」仅从侧栏注销，不删除磁盘文件。

### 5.2 配置 AI 服务商

使用对话功能前，需配置大语言模型 API 信息。

**操作步骤：**

1. 点击右侧图标栏的「设置」齿轮图标，或欢迎界面的「配置 AI」。
2. 在设置左侧导航选择「AI 服务商」。
3. 在「服务商」下拉框中搜索或选择内置服务商（如 DeepSeek、智谱、通义千问、豆包、Kimi、OpenAI 等），或选择「自定义」。
4. 填写以下信息：
   - **服务商名称**：自定义时填写；内置服务商名称不可修改。
   - **API Key**：在对应服务商控制台获取的密钥。
   - **API Base**：接口地址（选择内置服务商时通常自动填充）。
   - **模型**：从列表选择或手动输入模型名称；可点击刷新按钮拉取可用模型列表。
5. 点击「保存并应用」。
6. 返回对话界面，工作区状态显示为「就绪」。

**查看 API Key：**

- 点击 API Key 输入框旁的显示/隐藏按钮可切换掩码显示。
- 查看完整明文需在应用内确认（通过专用安全通道）。

### 5.3 开始第一次对话

1. 在工作区标题旁点击「+」新建对话，或点击「新对话」。
2. 在中央输入框底部输入任务描述，例如：「列出当前目录下的所有文件」。
3. 按 **Enter** 发送（默认发送方式，可在设置中改为 Ctrl+Enter）。
4. 等待 Agent 回复；若需调用工具，可能弹出权限确认（见第 14 章）。
5. 在消息列表中查看 Agent 的回复与工具执行过程。

## 6. 工作区管理

### 6.1 查看与展开工作区

1. 左侧边栏「工作区」区域显示当前工作区名称。
2. 点击工作区名称或右侧箭头，展开/折叠会话列表。
3. 悬停在工作区行上，显示操作按钮。

### 6.2 修改工作区名称

1. 悬停在工作区行，点击「⋯」打开选项菜单。
2. 选择「修改名称」。
3. 在弹窗中输入新名称，点击「确认」。

### 6.3 设置工作区外观

1. 点击工作区名称左侧的彩色圆点。
2. 在弹出面板中选择：
   - **颜色**：从 10 种预设色中选择。
   - **选择照片**：从本地选择图片作为标识。
   - **恢复自动**：清除自定义外观。

### 6.4 打开工作区文件夹

1. 点击工作区「⋯」菜单。
2. 选择「打开文件夹」。
3. 系统在默认文件管理器中打开该工作区根目录。

### 6.5 更换工作区目录

1. 点击工作区「⋯」菜单，选择「更换工作区」。
2. 在文件夹选择对话框中选取新目录。
3. 确认后，侧栏切换为新目录；旧目录文件保留在磁盘上。

### 6.6 移除工作区

1. 点击工作区「⋯」菜单，选择「移除」。
2. 在确认对话框中点击「确认」。
3. 工作区从侧栏移除；磁盘上的文件与会话数据不会被删除。

### 6.7 工作区本地目录结构

工作区根目录下由软件自动维护以下子目录（用户也可直接访问）：

| 目录 | 用途 |
|------|------|
| `sessions/` | 会话记录与消息数据 |
| `memory/` | 用户偏好与记忆笔记 |
| `skills/` | 可复用技能定义 |
| `workflows/` | 可复用工作流定义 |
| `uploads/` | 用户上传的附件 |
| `downloads/` | 下载的文件 |
| `outputs/` | Agent 生成的输出与工具结果 |
| `plugins/` | 工作区插件 |
| `.dipper-worker/` | 分组、权限、授权目录、外观等配置 |

全局配置（含 API Key 等敏感信息）存放在用户目录下的 `~/.dipper-worker/`。

## 7. 会话管理

### 7.1 新建对话

1. 展开工作区后，点击工作区标题旁的「+」，或分组标题旁的「+」。
2. 新会话出现在列表顶部，中央区域切换至空白对话页。
3. 在输入框输入首条消息开始对话。

### 7.2 切换对话

1. 在左侧会话列表中点击目标会话名称。
2. 中央区域加载该会话的历史消息。
3. 正在生成回复的会话行显示加载指示器。

### 7.3 置顶与取消置顶

1. 悬停在会话行，点击图钉图标；或打开会话「⋯」菜单。
2. 选择「置顶」将会话固定到「置顶」区域顶部；选择「取消置顶」恢复普通排序。

### 7.4 重命名会话

1. 打开会话「⋯」菜单，选择「修改名称」。
2. 输入新名称，点击「确认」。

### 7.5 归档与取消归档

1. 打开会话「⋯」菜单，选择「归档」。
2. 会话移至工作区底部的「已归档」区域。
3. 在已归档列表中，对会话选择「取消归档」可恢复至正常列表。

### 7.6 删除会话

1. 打开会话「⋯」菜单，选择「删除」（红色项）。
2. 在确认对话框中点击「确认」。
3. **注意：** 删除后无法恢复。

### 7.7 会话分组

**新建分组：**

1. 点击工作区「⋯」菜单，选择「新建分组…」。
2. 输入分组名称，点击「确认」。
3. 分组标题出现在会话列表中。

**将会话移入分组：**

1. 打开会话「⋯」菜单，在「移动到分组」子菜单中选择目标分组或「未分组」。
2. 或将会话行拖拽到分组标题上。

**管理分组：**

- 点击分组「⋯」菜单可「修改名称」或「删除分组」。
- 删除分组会同时删除组内所有会话（需确认）。

### 7.8 搜索会话与消息

1. 按 **Ctrl+Shift+F**（macOS：**⌘⇧F**），或点击边栏顶部搜索框。
2. 在搜索对话框中输入关键词。
3. 结果按「最近会话」「会话标题」「消息内容」分组显示。
4. 使用 **↑** / **↓** 键选择结果，按 **Enter** 打开；按 **Esc** 关闭对话框。
5. 若命中消息内容，打开会话后会定位到对应消息并启动对话内查找。

### 7.9 加载更多会话

当会话数量较多时，列表底部显示「加载更多」按钮，点击可加载更早的会话记录。

## 8. AI 对话

### 8.1 发送消息

1. 在中央底部输入框（Composer）中输入任务描述。
2. 点击右侧向上箭头按钮，或按配置的快捷键发送：
   - 默认：**Enter** 发送，**Shift+Enter** 换行。
   - 可选：**Ctrl+Enter** 发送，**Enter** 换行（在设置 → 快捷键中切换）。
3. 发送后输入框清空，消息出现在对话列表中。

### 8.2 停止生成

1. Agent 回复过程中，发送按钮变为方形「停止」按钮。
2. 点击「停止」可中断当前回合的生成。

### 8.3 排队发送

当 Agent 正在处理时，用户可继续输入：

1. 按 **Enter**（默认）：将消息加入队列，当前回合结束后自动发送。
2. 按 **Ctrl+Enter**：立即中断当前回合并发送新消息。
3. 队列面板显示在输入框上方，可对队列项上移、下移、移除，或点击「立即发送」。

### 8.4 添加附件

**方式一：点击附件按钮**

1. 点击输入框左侧的「回形针」图标。
2. 在文件选择对话框中选取一个或多个文件。
3. 附件显示在输入框上方，随消息一并发送。
4. 附件保存至工作区 `uploads/` 目录。

**方式二：拖放文件**

1. 将文件拖入输入框区域。
2. 出现「拖放文件以添加附件」提示时松开鼠标。
3. 文件加入待发送附件列表。

**方式三：粘贴图片**

1. 在输入框中按 **Ctrl+V**（macOS：**⌘V**）粘贴剪贴板中的图片。
2. 图片作为附件添加。

**方式四：截图**

见第 12 章；从输入框相机图标或全局快捷键发起，完成后可附加到当前消息。

### 8.5 选择模型

1. 在输入框工具栏点击模型选择器。
2. 搜索或浏览可用模型列表。
3. 选择模型后，该会话使用所选模型（覆盖全局默认）。
4. 选择「使用默认」恢复全局配置模型。

### 8.6 编辑与删除消息

**编辑用户消息：**

1. 右键点击自己的消息气泡。
2. 选择「编辑」。
3. 在编辑框中修改内容，点击「发送」或「取消」。

**删除消息：**

1. 右键点击消息气泡。
2. 选择「删除」。
3. 确认删除单条消息，或删除该轮用户消息及后续 Agent 回复。

**复制消息：**

- 右键选择「复制」或「全选」。

### 8.7 对话内查找

1. 按 **Ctrl+F**（macOS：**⌘F**），或点击对话标题栏的搜索图标。
2. 在右上角查找栏输入关键词（至少 2 个字符）。
3. 匹配内容高亮显示；点击「上一个」「下一个」或按 **Enter** / **Shift+Enter** 导航。
4. 按 **Esc** 关闭查找栏。

### 8.8 跳转到最新消息

长对话中向上滚动时，若 Agent 正在流式输出，输入框上方显示「跳转到最新」浮动按钮，点击可滚回底部。

### 8.9 建议卡片

新建空白会话时，界面可能展示最多 6 张 AI 生成的任务建议卡片。点击卡片可将建议内容填入输入框，便于快速开始常见任务。

### 8.10 Agent 交互提示

**权限确认（对话内）：**

当 Agent 请求执行敏感操作（如运行命令、访问文件、打开网页）时，在消息流中显示权限卡片：

- **拒绝**：不执行该操作。
- **允许一次**：仅允许当前操作。
- **始终允许**：本对话后续同类操作不再询问（危险命令与 MCP 仍会询问；重启应用后恢复询问）。

**问题确认（对话内）：**

Agent 需要用户补充信息时，显示问题卡片：

- 点击选项按钮选择答案，或在文本框输入后点击「提交」。
- 点击「修改请求」可回到输入框修改原始需求。

### 8.11 工具活动展示

## 14. 权限与安全

### 14.1 API 密钥保护

- API Key 仅存于操作系统安全存储（`secrets.json`，经 safeStorage 加密）。
- 设置界面与配置接口返回脱敏信息，不暴露明文密钥。
- 查看明文须经应用内确认流程。

### 14.2 操作权限门控

Agent 执行以下操作前可能请求用户确认：

- 运行终端命令
- 读写文件（超出自动授权范围）
- 打开网页或浏览器自动化
- MCP 工具调用
- 危险命令（即使已选「始终允许」仍会询问）

用户可在对话内卡片或权限设置中管理授权策略。

### 14.3 授权文件夹

- Agent 文件操作默认限制在工作区根目录及用户添加的授权文件夹内。
- 路径守卫阻止访问未授权路径。
- 网络守卫提供 SSRF 防护，限制异常出站请求。

### 14.4 数据本地存储

- 会话、记忆、技能等工作区数据保存在本地，不上传至 Dipper 服务器。
- 发往大语言模型的内容由本机组装与裁剪，用户可通过上下文策略控制上传范围。

## 15. 自我学习与记忆

### 15.1 功能说明

每个对话回合结束后，软件在后台静默分析交互内容，将高置信度信息沉淀为可复用资产，供后续对话自动加载。

### 15.2 沉淀内容类型

| 类型 | 存储位置 | 用途 |
|------|----------|------|
| 用户偏好与习惯 | `memory/USER.md` | 个性化回复与行为 |
| 项目事实与决策 | `memory/` 笔记 | 可检索的记忆 |
| 可复用经验 | `skills/*/SKILL.md` | Agent 技能，下次自动加载索引 |
| 可复用流程 | `workflows/*/WORKFLOW.md` | 带流程图与步骤的任务编排 |

### 15.3 用户可见行为

- 用户无需手动操作；Agent 在后续对话中自动引用相关记忆与技能。
- 低置信度结果自动丢弃，不写入磁盘。
- 学习日志记录在 `.dipper-worker/learning.jsonl`，默认不向用户弹窗打扰。

### 15.4 工作流（Workflow）

工作流定义多步骤任务的执行顺序与规则。用户可在 `workflows/` 目录查看或编辑 `WORKFLOW.md` 文件；Agent 匹配用户请求时按流程执行。详见项目 `docs/workflow/zh-cn/` 文档。

### 15.5 数据保留

全局配置 `~/.dipper-worker/worker.json` 中可选 `retention` 块控制记忆条数、工具结果保留时间、学习日志清理策略等；缺省使用内置默认值。

## 16. 工作区插件

### 16.1 功能说明

工作区插件允许向 Agent 注册自定义工具，扩展本地自动化能力。插件为工作区下的可信本地代码。

### 16.2 安装位置

```text
<工作区>/plugins/<插件目录>/
  manifest.json
  index.js（或 manifest 中 entry 指定的入口）
```

### 16.3 安装步骤（用户侧）

1. 将插件包文件夹复制到工作区 `plugins/` 目录下。
2. 确保包含有效的 `manifest.json`（`kind: "tool-pack"`）。
3. 重新打开工作区或等待空闲时自动热重载。
4. Agent 在后续对话中可调用插件注册的工具。

### 16.4 注意事项

- 插件在同一工作区的共享子进程中加载，属同一信任域。
- 不可覆盖内置工具包 ID 或内置工具名称。
- 示例插件见项目 `examples/plugins/echo-pack/`。
- 开发与部署细节见 `docs/zh_cn/PLUGINS.md`。

## 19. 常见问题

### 19.1 无法开始对话，显示「待配置」

**原因：** 未配置 AI 服务商或 API Key / 模型无效。

**处理：** 进入设置 → AI 服务商，检查 API Key、API Base 与模型名称，点击「保存并应用」。

### 19.2 Agent 无响应或报错

**可能原因：**

- 网络无法访问 API 端点。
- API Key 余额不足或已失效。
- 模型名称错误或已下线。

**处理：** 检查网络；在服务商控制台核实密钥与额度；尝试刷新模型列表并更换模型。

### 19.3 权限请求频繁

**处理：** 在对话内权限卡片选择「始终允许」（危险操作仍会询问）；或在设置 → 权限中预先添加常用授权文件夹。

### 19.4 关闭窗口后如何重新打开

点击系统托盘中的 Dipper Worker / AI Worker 图标，或双击托盘图标。

### 19.5 会话数据存在哪里

工作区目录下的 `sessions/` 及 `.dipper-worker/`；全局配置在 `~/.dipper-worker/`。

### 19.6 如何切换界面语言

设置 → 外观 → 语言，选择「中文」「English」或「跟随系统」。

### 19.7 长对话变慢或费用升高

软件自动裁剪上下文并支持会话摘要压缩。用户可归档旧会话、新建对话分流主题，或在设置中调整 Agent 参数与上下文策略。

### 19.8 如何完全退出应用

右键系统托盘图标，选择「退出 AI Worker」。
