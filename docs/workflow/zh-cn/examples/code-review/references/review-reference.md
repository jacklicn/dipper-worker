# Code Review 参考表（Level 3，按需加载）

本文件在审查流程中被 `WORKFLOW.md` 引用时加载。长表格与规则明细放在这里，保持 `WORKFLOW.md` 主体精炼。

## 问题严重度分级

| 级别 | 含义 | 处理 |
| --- | --- | --- |
| `error` | 编译失败、明显安全漏洞、逻辑必然错误 | 报告中置顶高亮，给出修复建议 |
| `warning` | 潜在 bug、资源泄漏、未处理错误路径、可疑逻辑 | 列出并给出建议 |
| `note` | 风格、可读性、性能提示 | 仅列出，不阻塞 |

## 优先检查项

1. 未捕获异常 / 吞掉错误（`catch {}`、`except: pass`）
2. 硬编码密钥、凭据、URL 中的 token
3. 路径拼接越界（`../`、绝对路径逃逸沙箱）
4. 注入风险：`exec` / `eval` / 拼接 SQL / shell 命令拼接用户输入
5. 资源未释放（文件句柄、子进程、定时器）
6. 竞态与并发（共享可变状态、Promise.allSettled 误用）
7. 超长函数 / 重复代码（提示重构）

## 报告模板

```markdown
# 代码审查报告

- 审查范围: <目标>
- 时间: <ISO 时间>
- 文件数: <N>

## 致命问题
- [error] <文件>:<行> <描述> → <建议>

## 警告
- [warning] <文件>:<行> <描述> → <建议>

## 提示
- [note] <文件>:<行> <描述>

## 总体结论
<一段话总结代码质量与风险>
```
