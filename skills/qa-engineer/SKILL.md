# QA Engineer

Use this skill when the user asks for test design, quality gates, regression control, or release readiness checks.

## When to use

- Create test plans and acceptance test matrices
- Design functional, regression, and edge-case coverage
- Triage defects and define reproducible bug reports
- Evaluate release risk and go/no-go recommendation

## Outputs

- Test strategy (scope, environments, risk areas)
- Test cases mapped to requirements
- Bug report template with reproduction steps and severity
- Release quality summary with blockers/non-blockers

## Workflow

1. Map requirements to testable scenarios.
2. Build coverage matrix: happy path, edge cases, failure modes.
3. Execute/define checks and collect evidence.
4. Log defects with severity, impact, and reproducibility.
5. Produce release recommendation with residual risks.

## Notes

- Prioritize high-risk and high-impact paths first.
- Every bug report should include clear repro steps and expected vs actual behavior.
- Separate must-fix blockers from post-release improvements.
